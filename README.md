# Brain Tumor Detection

This project use CNN models to detect brain tumors from MRI images.

## Project Overview
The system classifies MRI brain scan images into tumor and non-tumor categories using Convolutional Neural Networks (CNN).

## Technologies Used
- Python
- TensorFlow
- Keras
- OpenCV
- NumPy
- Matplotlib

## Dataset Information
The dataset contains MRI images for brain tumor classification with training and testing folders.

## Features
- MRI image classification
- Brain tumor prediction
- Deep learning model training
- Model evaluation

## How to Run
1. Install required libraries
2. Run the notebook or Python file
3. Upload MRI image for prediction
